### About

I analyze client-side protection systems: obfuscated JavaScript, custom bytecode VMs, browser fingerprinting and payload encryption. My work focuses on understanding how these mechanisms are built, documenting them clearly and using that knowledge to design stronger defenses.

### Services

- **Reverse engineering** of obfuscated JavaScript and WebAssembly
- **Bot-mitigation and fingerprinting analysis**: how signals are collected, structured and protected
- **JavaScript VM analysis**: opcode recovery, disassembly, deobfuscation tooling
- **Security assessments** of web applications and APIs
- **Full-stack development**: backends, APIs and web frontends
